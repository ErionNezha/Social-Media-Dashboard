# Paneli Social

Ndiq rritjen tënde në rrjete sociale — statistika, grafikë dhe dark/light mode.

## Veçori

- 4 karta statistikash: Ndjekës, Pëlqime, Shikime, Komente — me % krahasimi (▲/▼)
- Grafik vije në canvas: rritja e ndjekësve (mbushje gradient + pika)
- Bar chart në canvas: angazhimi javor me 7 shtylla dhe etiketa ditësh
- Ndërrim platforme: Instagram / TikTok / YouTube — të dhënat ndryshojnë me animacion numërimi
- Butonat 7D / 30D rigjenerojnë seritë e grafikut
- Switch dark/light mode (🌙/☀️) — light mode me sfond të çelët elegant
- Vizatim manual me canvas 2D (pa librari), i përgjigjet ndryshimit të madhësisë
- Etiketim i qartë: të dhëna të simuluara për demonstrim
